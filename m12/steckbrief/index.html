Wie viele Angaben braucht eine Kurve 3. Grades?

Ansatz $f(x) = ax^3 + bx^2 + cx + d$: vier Unbekannte. Jede Angabe über $G_f$ wird zu einer Gleichung.

1Entdecken

Ausprobieren
Machen Sie aus dem Bündel genau eine Kurve.
Aha! Vier Unbekannte brauchen vier verschiedene Angaben. Jede neue Gleichung streicht eine Möglichkeit. Eine Angabe, die man schon kennt, ändert nichts, auch wenn sie anders klingt.
2Warum?
•
Ganzrationale Funktion $n$-ten Grades: $n + 1$ Koeffizienten, also $n + 1$ verschiedene Bedingungen.
•
$P(x_0\,|\,y_0)$ liegt auf $G_f$ $\Rightarrow$ $f(x_0) = y_0$. Die Tangente an der Stelle $x_0$ hat die Steigung $m$ $\Rightarrow$ $f'(x_0) = m$. $x_0$ ist Wendestelle von $f$ $\Rightarrow$ $f''(x_0) = 0$.
•
Hier: $d = 1$, $\;27a + 6b + c = 0$, $\;12a + 2b = 0$, $\;64a + 16b + 4c + 1 = 5$. Lösung: $f(x) = x^3 - 6x^2 + 9x + 1$.
Typischer Fehler: Eine Angabe mitzählen, die schon aus den anderen folgt, zum Beispiel $f'(0) = 0$, wenn $G_f$ achsensymmetrisch ist. Zu wenige Bedingungen: unendlich viele Funktionen.
