4. Cookies und lokaler Speicher

Diese Website setzt keine Cookies. Im localStorage Ihres Browsers werden nur gespeichert: die gewählte Darstellung (hell/dunkel) und auf einzelnen Übungsseiten Ihr Fortschritt (zum Beispiel gelöste Level). Diese Daten verlassen Ihren Browser nicht und werden nicht an den Server übertragen. Sie können sie jederzeit in den Browsereinstellungen löschen.

Damit die Übungsseiten auch ohne Internet funktionieren, legt Ihr Browser beim ersten Besuch eine Kopie der Seiten, Schriften und Formeln im Speicher des Geräts ab (Service Worker und Cache, etwa 2 MB). Erklärvideos werden nur gespeichert, wenn Sie unter dem Video auf „offline speichern“ tippen; mit „Entfernen“ löschen Sie sie wieder. Auch diese Kopien bleiben auf Ihrem Gerät, es werden dabei keine Daten über Sie an den Server übertragen. Sie lassen sich in den Browsereinstellungen unter „Websitedaten löschen“ vollständig entfernen.
