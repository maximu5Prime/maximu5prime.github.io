M12+ · Allgemeine Sinusfunktion

Was machen a, b, c, d mit der Sinuskurve?

$f(x) = a\cdot\sin(bx - c) + d$ — vier Regler, sechs Zielkurven.

1Ausprobieren

Legen Sie Ihre Kurve genau auf die gestrichelte Zielkurve.
Deckung
Aha! Die Kurve wandert nicht um $c$, sondern um $\dfrac{c}{b}$: $$\sin\bigl(2x - \tfrac{\pi}{2}\bigr) = \sin\bigl(2\,(x - \tfrac{\pi}{4})\bigr)$$
Zusatz: Vom Riesenrad zur Sinuskurve

Gondel aus dem Skript: Einstieg unten in $2\,\text{m}$ Höhe, Nabe $27\,\text{m}$ hoch, eine Umdrehung in $10$ Minuten.

Eine ganze Umdrehung fahren: Welche Größen des Rads stecken in der Kurve?
t = 0 min
Aha! Mittellinie = Höhe der Nabe, Amplitude = Radius, Periode = Umlaufzeit. Und die Verschiebung? Wann fährt die Gondel auf Nabenhöhe nach oben?
2Warum?
•
Die Sinuskurve „startet“ (Mittellinie, steigend), wo das Argument null ist: $bx - c = 0$.
•
Auflösen: $x = \dfrac{c}{b}$ — das ist der neue Startpunkt, also die Verschiebung.
•
Dasselbe sieht man durch Ausklammern: $\;bx - c = b\bigl(x - \tfrac{c}{b}\bigr)$.
Typischer Fehler: $\sin(2x - \pi)$ „um $\pi$ nach rechts“. Richtig ist $\frac{\pi}{2}$, denn $\sin(2x - \pi) = \sin\bigl(2(x - \tfrac{\pi}{2})\bigr)$.
