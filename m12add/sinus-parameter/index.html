M12+ · Allgemeine Sinusfunktion

Was machen a, b, c, d mit der Sinuskurve?

$f(x) = a\cdot\sin(bx - c) + d$ — vier Regler, eine Kurve. Bewegen Sie erst jeden Regler einzeln und vergleichen Sie mit $\sin(x)$ (grau). Dann nehmen Sie sich die Zielkurve vor.

Ihr Auftrag: Legen Sie Ihre Kurve genau auf die gestrichelte Zielkurve.
Deckung
Aha! Die Kurve wandert nicht um $c$, sondern um $\dfrac{c}{b}$. Für die Zielkurve (um $\frac{\pi}{4}$ nach rechts, $b = 2$) braucht man deshalb $c = \frac{\pi}{2}$: $$\sin\bigl(2x - \tfrac{\pi}{2}\bigr) = \sin\bigl(2\,(x - \tfrac{\pi}{4})\bigr)$$
Warum? Klammern Sie $b$ aus
1
Die Sinuskurve „startet“ (Mittellinie, steigend), wo das Argument null ist: $bx - c = 0$.
2
Auflösen: $x = \dfrac{c}{b}$ — das ist der neue Startpunkt, also die Verschiebung.
3
Dasselbe sieht man durch Ausklammern: $\;bx - c = b\bigl(x - \tfrac{c}{b}\bigr)$.
Typischer Fehler: $\sin(2x - \pi)$ „um $\pi$ nach rechts“. Richtig ist $\frac{\pi}{2}$, denn $\sin(2x - \pi) = \sin\bigl(2(x - \tfrac{\pi}{2})\bigr)$.
