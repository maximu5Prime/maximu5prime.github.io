Ein linearer Parameter k, unendlich viele Funktionen.

Ein linearer Scharparameter

Merksatz: Enthält eine Funktionsvorschrift zusätzlich zu $x$ einen Parameter $k$, der linear vorkommt (nicht als $k^2$ o.ä.), beschreibt sie eine ganze Schar von Funktionen. Aufgaben werden zunächst allgemein in Abhängigkeit von $k$ gelöst, konkrete Werte setzt man erst am Ende ein.

Beispiel: $f_k(x) = x^3 - kx$ — für jeden Wert von $k$ ergibt sich ein anderer Graph.

Nullstellen einer Schar in Abhängigkeit von k

Beispiel: $f_k(x) = x^3-kx = x(x^2-k)$.

$$x=0 \text{ (immer)}, \qquad x=\pm\sqrt{k} \text{ (nur falls } k>0)$$

Für $k=0$: nur eine (dreifache) Nullstelle bei $x=0$. Für $k<0$: $x^2-k=0$ hat keine reelle Lösung, also bleibt $x=0$ die einzige Nullstelle. Die Punktsymmetrie zum Ursprung bleibt für jeden Wert von $k$ erhalten (nur ungerade Exponenten).
