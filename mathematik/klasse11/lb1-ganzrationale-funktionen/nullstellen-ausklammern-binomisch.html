Nullstellen:
Ausklammern & binomische Formeln

Produkt gleich null heißt: Einer der Faktoren ist null. Ausklammern und binomische Formeln bringen den Term in Produktform.

Eine Nullstelle ist ein $x$, für das $f(x) = 0$ gilt — dort schneidet oder berührt der Graph die $x$-Achse. Der Schlüssel zum Rechnen ist der Satz vom Nullprodukt:

$$a \cdot b = 0 \;\Leftrightarrow\; a = 0 \;\text{ oder }\; b = 0$$

Ausklammern: Steckt in jedem Summanden ein $x$, lässt sich die kleinste Potenz herausziehen — eine Nullstelle liegt dann sofort bei $x = 0$.

Binomische Formeln rückwärts: Muster wie $a^2 - 2ab + b^2 = (a-b)^2$ oder $a^2 - b^2 = (a-b)(a+b)$ zerlegen den Rest ohne weitere Rechnung.

Wie oft ein Faktor vorkommt, entscheidet über das Verhalten an der Nullstelle — siehe Vielfachheit. Und wenn sich kein Muster findet, hilft die Polynomdivision.

f(x) = x · (x − 3)² — Nullstelle antippen!

Tippe eine Nullstelle an: Der zugehörige Faktor wird angezeigt. Bei $x=0$ schneidet der Graph (einfach), bei $x=3$ berührt er nur (doppelt).

Rechenbeispiel

Gesucht: alle Nullstellen von $f(x) = x^3 - 6x^2 + 9x$.

Schritt 1 · Ausklammern. In jedem Summanden steckt ein $x$:

$$f(x) = x \cdot \bigl(x^2 - 6x + 9\bigr)$$

Schritt 2 · Binomische Formel erkennen. $x^2 - 6x + 9$ passt auf $a^2 - 2ab + b^2$ mit $a = x$, $b = 3$:

$$f(x) = x \cdot (x - 3)^2$$

Schritt 3 · Satz vom Nullprodukt. Jeder Faktor kann null werden:

$$x = 0 \qquad\text{oder}\qquad (x-3)^2 = 0 \;\Leftrightarrow\; x = 3$$
Nullstellen: $x_1 = 0$ (einfach — der Graph schneidet) und $x_2 = 3$ (doppelt — der Graph berührt die Achse nur).
