Gemeinsame Punkte
zweier Graphen

Gleichsetzen, alles auf eine Seite bringen, Nullstellen suchen — Schnittpunkte sind ein Nullstellenproblem in Verkleidung.

An einem gemeinsamen Punkt haben beide Graphen denselben $y$-Wert:

$$f(x) = g(x) \;\Leftrightarrow\; f(x) - g(x) = 0$$

Die Differenzfunktion $d(x) = f(x) - g(x)$ verwandelt die Frage in eine gewöhnliche Nullstellensuche — mit allen bekannten Werkzeugen: Ausklammern, Polynomdivision, Mitternachtsformel.

Die $y$-Koordinaten liefert danach das Einsetzen in $f$ oder $g$ (Funktionswert berechnen — beide müssen dasselbe ergeben, gute Probe!).

Ist eine Lösung eine doppelte Nullstelle von $d$, schneiden sich die Graphen dort nicht, sondern berühren sich — die Vielfachheit entscheidet.

$f(x) = x^2 - 2$ und die Gerade $g(x) = x + c$: Verschiebe $c$ — bei $c = -2{,}25$ berühren sich die Graphen (doppelte Nullstelle der Differenz), darunter gibt es keinen gemeinsamen Punkt mehr.

Rechenbeispiel

Gemeinsame Punkte von $f(x) = x^3 - 2x$ und $g(x) = x$.

Schritt 1 · Gleichsetzen und ordnen.

$$x^3 - 2x = x \;\Leftrightarrow\; x^3 - 3x = 0$$

Schritt 2 · Nullstellen der Differenz. $x$ ausklammern:

$$x\,\bigl(x^2 - 3\bigr) = 0 \qquad\Rightarrow\qquad x = 0,\quad x = \pm\sqrt{3}$$

Schritt 3 · $y$-Werte über $g$. $g(x) = x$, also:

$$S_1(0\,|\,0), \qquad S_2\bigl(\sqrt{3}\,\big|\,\sqrt{3}\bigr), \qquad S_3\bigl(-\sqrt{3}\,\big|\,{-\sqrt{3}}\bigr)$$
Drei Schnittpunkte. Probe mit $f$: $f(\sqrt{3}) = 3\sqrt{3} - 2\sqrt{3} = \sqrt{3}$ ✓
